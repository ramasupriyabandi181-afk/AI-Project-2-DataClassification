# DecodeLabs Project 2 - Data Classification Using AI

## Project Overview

This project is part of the DecodeLabs Artificial Intelligence
Industrial Training Kit.

The objective is to build a basic classification model using
a small dataset and demonstrate the fundamental supervised
learning workflow.

## Objective

The main objectives of this project are:

- Load and understand a dataset
- Split the dataset into training and testing sets
- Apply a classification algorithm
- Train the machine learning model
- Test the model
- Evaluate the model's performance

## Dataset

The Iris dataset is used for this project.

The dataset contains four input features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable is:

- Setosa
- Versicolor
- Virginica

## Algorithm Used

Decision Tree Classifier.

A Decision Tree is a supervised machine learning algorithm
used for classification and prediction.

## Technologies Used

- Python
- Pandas
- Scikit-learn
